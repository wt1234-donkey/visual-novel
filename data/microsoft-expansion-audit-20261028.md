## 组织与沿革

- Microsoft的1975年公司创立与[2000年3月设立专门游戏部门](https://news.microsoft.com/source/2000/03/10/microsoft-unveils-plans-for-xbox/)分开。2000公告不能证明“Xbox Game Studios”名称当时存在。
- [2006年4月6日收购公告](https://news.microsoft.com/source/2006/04/06/microsoft-game-studios-acquires-video-game-luminary-peter-molyneuxs-lionhead-studios/)确认Lionhead加入Microsoft Game Studios，且两者此前已在Fable合作。关系从2006年开始，不追溯2004年的Fable开发身份。
- [2018年11月公告](https://news.xbox.com/en-us/2018/11/10/obsidian-inxile-join-microsoft-studios/)说明Obsidian加入的计划；[微软投资者收购史](https://www.microsoft.com/en-us/Investor/Acquisition-History)列11月10日收购。关联只表明组织归属，仍以Obsidian原名记录《Avowed》开发。
- [2019年2月5日官方公告](https://news.xbox.com/en-us/2019/02/05/introducing-xbox-game-studios/)明确Microsoft Studios更名Xbox Game Studios。旧Microsoft Game Studios、Microsoft Studios和新Xbox Game Studios发行署名不合并成跨年代单一原文。
