# 公司与品牌关系页首版预览

日期：2026-10-22。独立页面：`relationships-preview.html`，未替换现有主库、主体档案或专题页。

## 展示方式

参考[鲲Galgame的会社页面](https://www.kungal.com/galgame/official/15437)中企业家族、更名沿革与衍生的分区逻辑，使用本站自己的页面、数据和样式。预览覆盖7个家族；提供名称／旧名搜索、节点选择、分支折叠、关系树／列表、缩放、待核线索开关、主体详情及作品／专题跳转。

- 主树：母公司／子公司、品牌运营和品牌家族分别标注，不把后两者自动解释为股权。
- 名称沿革：只读取明确的更名记录，不把检索别名自动当作旧名。
- 衍生：与公司归属分开；待核线索使用虚线和“待核”标签，可关闭。
- 数量：仅统计该主体直接参与的作品ID，不沿母公司、品牌或衍生边继承；制作记录和其他参与分开计数，不宣称题材或风格一致。

2. Microsoft Studios→Xbox Game Studios：依据[2019-02-05 Xbox官方更名公告](https://news.xbox.com/en-us/2019/02/05/introducing-xbox-game-studios/)。保留原来两个历史署名ID，不进行合并或回填。

4. Silky’s→Silky’s Plus：只展示“成员独立”待核线索。既有档案区分原品牌与独立品牌，但本轮未成功读取新的原始独立公告；不能据此确认公司衍生、母子公司或旧作继承。因此使用pending，而非sourceReviewed。

生成脚本`build_relationships_preview.py`只读取原档案和上述配置，输出轻量页面快照`relationships-preview.json`。该快照仅用于页面，不能作为新的权威身份索引。
