# Square作品、操作与内容核对（2026-10-18）

维护目标：wt1234-donkey/visual-novel。

## 范围与结果

根据用户此前“列出Carry Lab（キャリーラボ）游戏类型清单”项目的Square清单建立独立专题。找回的上下文明确1984—2003年3月底、普通移植不重复，以及主要系列与Satellaview作品；逐字原表未完整恢复。本轮以官方产品目录及每个产品的game.json、原厂手册、任天堂访谈、原作画面对照补核，不宣称全球完整目录或完整版本史。

- 官方公司沿革记1986年9月设立；1984—1986软件部门作品依历史署名保留。2003年4月1日后独立新作不倒算原Square。
- 主库新增5部；复用g076、g081旧输入式记录，不改旧对象。
- 跨类型新增62部剧情RPG／战术RPG／混合动作叙事；已有Hao君及Deep Dungeon三作只链接原专题，不制造副本。
- Alpha、鲁德拉秘宝、FFXI共3部仅专题书目，无内容或平台记录。
- 正文72张作品卡（69个有发行记录身份及3部仅专题书目）；末尾138行／6组参考表，含合集、地区发行、非叙事、待核及取消计划，不是138部独立游戏。
- 主库增加5原作内容／5条首次发行；关联区62原作内容＋8项增补＝70个内容／74条首次发行。合计本轮75个内容、79条发行。当前主库1208作品／1406内容／2400发行；关联665、仅专题书目125、专题74。

## 操作准入

| 边界 | 处理 |
|---|---|
| 水晶之龙 | 官方说明图标指令与场景光标；无词句键入。杂志虚构野球拳不采作玩法。 |
| 克娄巴特拉的魔宝 | 原厂说明书明确菜单移动、物品、攻击、逃跑及谜题；官方RPG定位保留在复合类型，主库图文选项入口不重复建立RPG卡。 |
| 中山美穗 | 预设指令、回应与情绪选择；外部电话服务不等于全程游戏角色配音。 |
| Radical Dreamers | 给定行动与故事分支，七篇内容归一作品；声效小说不自动等于角色配音。 |
| Another Mind | 从预设词语／句式组句；不是自由键入会话。官方product game.json与操作考证共同支持。 |
| FFII关键词 | 原厂手册“记住／询问”从已获得词语选择，不是自由文本。 |
| 鲁德拉 | 自由输入文字创建言灵并决定魔法效果，是实际玩法，排除本次数据库新增。 |
| FFXI | 有自由聊天与斜杠行动命令，即使支持菜单仍只列专题。 |
| Blassty | 方向数字键、固定功能键、选择确认；固定键盘控制与文字解析分开。 |
| Dynami Tracer | 原作事件／菜单对照确认剧情探索，无常规RPG战斗，不添加战斗指令。 |
| Treasure Conflix | 飞行、空战、城镇菜单与线索寻宝，按混合叙事关联。原作首配日异文只取1996年。 |
| 名字、存档、固定口令 | 不作自由行动词句输入；FM3的预设邮件与固定资料密码、Live A Live固定机关码分开说明。 |

角色采用官方档案中具名人物或明确身份，不用当前续作人物补造原作角色。大多数早期RPG产品说明不是完整操作手册，标签归纳主要已知操作，不声称穷尽小游戏或每个平台控制。本轮无配音完整审计：直接有角色表演／官方声音说明的部分记录标有，其余保留未核实。

## 验证与保留

要求：数据校验、Python全套、Node全套、生成页同步检查及git diff --check。发布前比较所有旧主库作品、内容、平台发行、73个旧公司对象和旧专题页面，确保本轮只增加Square与入口，不改旧历史对象。原清单恢复与未核版本的局限已随专题公开。

本轮结果：数据校验通过；15项Python与169项Node测试全部通过；生成页一致性、差异空白检查通过。原1203作品、1401内容、2395发行及73个旧公司对象／页面逐项保持。
